Purpose of this testing is to verify that the code
for this project works as expected when using the GPT4All library.
The code compares two developer records to determine if they are the same person.
The records come from a csv file which has been generated by the bird heuristic and the 
heuristic has determined the, to be the same person. The goal it to find the false positives
and improve the accuracy of bird heuristic.

Testing ensures that is_same_person() and process_csv() function function correctly and it also
test that the GPT4All model loads and functions as it should.
The sematic accuracy of the model is out of scope for this and so are performance benchmarks and comparisons to other models.

Testing will be done using Pytest using unit tests.

Test cases
Test 1:  Tests if the persons are same for 
"Alice Johnson", "alice@example.com",
"Alice Johnson", "alice@example.com"
expected result = SAME

Test 2: Tests if the persons are same for
"Alice Johnson", "alice@example.com",
"Bob Smith", "bobberoo@example.com"
expected result = DIFFERENT

Test 3: Test if csv processing works.
Expected to parse csv correctly.

Estimated coverage is about 80% (real coverage was 75%)
